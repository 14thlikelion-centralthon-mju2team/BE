3. 문제정의
3.1 현재사용자의행동
사용자는 외출 전 캘린더에서 시간과 장소를 확인하고, 지도에서 이동 시간을 검색하며, 날씨 앱에서 강수·자외선·미세먼지·기
온을 확인한다. 이후 준비 시작 시각을 감으로 역산하고 필요한 물품과 행동을 스스로 판단한다.
3.2 핵심시간관리문제
기존 지도 앱은 사용자가 이미 준비를 마쳤다는 것을 전제로 한다. 그러나 실제 외출에는 씻기, 옷 선택, 화장과 헤어, 준비물 챙
기기, 개인 루틴, 현관문을 나서기 전 지연이 포함된다. 사용자는 자신의 준비 시간을 실제보다 짧게 예상하거나 준비 시작 시점
을 놓쳐 늦거나 촉박하게 도착한다.
3.3 웰니스행동의단절
날씨와 환경 정보는 이미 제공되지만 대부분 숫자와 아이콘으로 끝난다. 사용자는 자외선이 높다는 것을 확인하고도 선크림을
챙기지 못하거나, 야외 이동이 길어도 재도포 시점을 놓치며, 미세먼지·폭염·일교차에 필요한 준비를 매번 따로 판단해야 한다.
3.4 자기보고준비시간의부정확성
온보딩에서 입력한 평균 준비 시간은 검증되지 않은 자기 보고다. 늦는 사용자가 자신의 준비 시간을 과소평가할 가능성이 있으
므로 입력값은 첫 계획을 만드는 시드로만 사용하고, 실제 준비·출발·도착 기록으로 교정해야 한다.
3.5 핵심문제문장
사람들은 제시간에 도착하기 위해 반복적으로 서두르지만, 실제로 필요한 것은 자신에게 맞는 준비 계획과 환경에 맞는 웰니
스 행동이다.
3.6 Ensom 의해결방향
Ensom은 실제 행동 편차와 환경 노출을 함께 계산해, 늦지 않으면서도 서두르지 않고 필요한 웰니스 행동까지 놓치지 않는
일정 계획을 제공한다.

검증 방법: 사전 설문에서 자기 보고 준비 시간과 가장 최근 실제 준비 시간을 비교한다.

다.
검증 방법: 준비 시작 알림과 출발 알림의 반응률, 실제 행동 시작률을 비교한다.
가설3. 실패기록은자기보고보다빠르게개인계획을교정한다
준비 시작 지연, 실제 준비 초과, 출발 지연, 교통 지연을 구분하면 잘못된 요소만 조정할 수 있다.
검증 방법: 고정 계획군과 실패 기록 보정군의 준비 시간 오차와 정시 도착률을 비교한다.

자외선, 미세먼지, 체감온도, 강수와 예상 야외 이동 시간을 결합해 일정별 웰니스 행동 우선순위를 계산한다. 지도 위에 정보를
겹쳐 보여주지 않고 홈 카드, 준비 체크리스트, 푸시 알림으로 행동을 제안한다.
7.5 맥락형웰니스이벤트푸시
사용자가 선택한 항목과 간격, 일정의 야외 노출 조건이 일치할 때만 선크림 재도포·물 챙기기·마스크 확인 같은 리마인드를 제
공한다. 이 알림은 기본 시간 알림과 분리해 사용자가 켜고 끌 수 있다.
7.6 최소입력기반결과확인
준비 시작은 원탭으로 기록하고, 출발·도착은 지오펜싱이 가능한 경우 자동 확인한다. 자동 판단이 불확실할 때만 짧은 확인 질
문을 제공한다.
7.7 회원계정기반연속성
일정, 준비 패턴, 웰니스 선호, 알림 반응과 리포트는 로그인한 회원 계정에 귀속된다. 기기를 바꾸거나 다시 로그인해도 사용자
의 계획 맥락을 복구한다.
8. 제품설계원칙
8.1 빠르게가아니라적절하게
모든 사용자에게 일찍 출발하라고 요구하지 않는다. 실제 행동과 일정 조건을 바탕으로 적절한 준비 시점을 제안한다.
8.2 늦음과서두름을함께줄인다
정시 도착률뿐 아니라 준비 시작 지연, 극한 알림 발생, 촉박 평가, 과도하게 이른 도착을 함께 본다.
8.3 정보가아니라행동을제안한다
자외선 수치보다 선크림 준비, 미세먼지 등급보다 마스크 확인, 이동 시간보다 출발 시각처럼 즉시 실행 가능한 문장으로 변환한
다.
8.4 웰니스제안은맥락이있을때만한다
야외 이동 시간과 사용자 설정이 관련 없는 경우 일반적인 뷰티·건강 팁을 노출하지 않는다.

8.5 추천근거를확인할수있어야한다

현재 위치, 출발지, 목적지, 경로, 예상 시간과 캘린더 저장만 제공한다. 고급 시각화와 센서 기반 안내는 MVP 에서 제외한다.

실패는 계획 편차로 표현하고 웰니스 점수는 의료 위험도나 피부 상태 점수가 아닌 알림 우선순위로만 사용한다.
8.8 사용자통제가기본값이다
웰니스 항목, 재알림 간격, 잠금화면 노출, 위치 자동 확인, 개인화 적용을 사용자가 직접 끌 수 있어야 한다.

• 환경 웰니스 영역: 선크림·마스크·물처럼 현재 일정과 날씨에 관련된 행동을 최대 3 개 노출한다.

12.4 시간계산식
목표 도착 시각 = 일정 시작 시각 - 도착 여유 시간
권장 출발 시각 = 목표 도착 시각 - 예상 이동 시간 - 교통 버퍼
준비 시작 시각 = 권장 출발 시각 - 개인 준비 시간 - 상황별 추가 준비 시간 - 개인 루틴 시간
개인 준비 시간은 온보딩 입력값을 고정해 쓰지 않고 16.2 의 보정 모델이 산출한 값을 사용한다.

12.6 외출전웰니스준비

림 확인을 추가한다. 사용자 맞춤 항목은 사용자가 직접 등록한 사실에 기반하고, 환경 웰니스 행동은 일정과 날씨가 관련 있을

13. 알림체계

동의하는 맥락형 알림으로 분리한다.

13.3 돌발알림
교통·강수·기온 변화로 기존 계획을 수정해야 할 때 제공한다. 사소한 변화는 푸시하지 않고 로그에만 기록한다.
13.4 웰니스이벤트알림
• 사용자가 선택한 항목에만 발송한다.
• 일정과 야외 노출 맥락이 있어야 한다.
• 기본 예시는 선크림 재도포 확인, 수분 보충, 마스크 확인이다.
• 완료·미루기·오늘은 그만 액션을 제공한다.
• 같은 일정의 동일 항목은 기본 1 회로 제한한다.
13.5 알림수제한
• 일정당 시간 관리 핵심 알림은 기본 최대 3 회다.
• 웰니스 이벤트 알림은 별도 동의 시 일정당 기본 최대 1 회다.
• 준비·출발·완료 상태가 확인되면 불필요한 알림을 취소한다.
• 사용자가 연속으로 무시하거나 오늘은 그만을 선택하면 빈도를 낮춘다.
• 알림 문구에 건강 효과를 확정적으로 표현하지 않는다.
14. 웰니스모델
14.1 정의
Ensom 의 웰니스 기능은 건강 상태를 진단하거나 치료하는 기능이 아니다. 일정과 이동 환경을 바탕으로 외출 전·중·후에 필

14.2 입력데이터

• 미세먼지 또는 대기질 등급

16. AI 및백엔드요구사항
16.1 일정텍스트분류
일정 제목, 장소, 설명과 화상회의 링크를 이용해 온라인 여부, 이동 필요 여부, 장소 누락, 일정 유형을 판단한다. 사용자가 지정
한 장소 필요 여부가 항상 우선하며 신뢰도가 낮으면 한 번 확인한다.
16.2 준비시간모델
설계 원칙은 자기 보고는 시드이고 관측된 편차가 진실이라는 것이다.
신호 정의 성격
t_plan_prep 서비스가 권장한 준비 시작 시각 계획값
t_actual_prep 사용자가 준비 시작을 누른 시각 관측값
t_plan_depart 권장 출발 시각 계획값
t_actual_depart 사용자 입력 또는 위치 기반 출발 시각 관측값
t_arrive 실제 또는 확인된 도착 시각 관측값
snooze_count 5 분 뒤 알림 선택 횟수 관측값
outcome 정시·촉박·지각·건너뜀 관측값
준비 시작 지연 Dprep = t_actual_prep - t_plan_prep
출발 지연 Ddepart = t_actual_depart - t_plan_depart
실제 준비 소요 Dactual = t_actual_depart - t_actual_prep
도착 여유 margin = 일정 시작 시각 - t_arrive

기존 서비스는 정보를 보여주지만 Ensom 은 준비 시작 시각을 먼저 제안하고 실제 행동 편차를 학습합니다. 여기에 환경과 야
외 이동 시간을 행동 제안과 이벤트 푸시로 변환하고 일정 후 회복까지 연결합니다.
28.3 왜웰니스일정관리비서인가요?
사용자의 문제는 늦는 것뿐 아니라 늦지 않기 위해 반복적으로 서두르고 외출 환경에 필요한 준비를 놓치는 것입니다. Ensom
은 시간 부담과 환경 대응을 같은 일정 안에서 관리합니다.
28.4 지도기능을왜기본수준으로제한했나요?

32. 최종제품요약
Ensom 은 일정을 기록하거나 목적지까지의 길만 안내하는 서비스가 아니다. 캘린더 일정, 실제 준비 시간, 영양제·개인 기호
품목을 포함한 사용자 맞춤 준비물과 루틴, 교통, 날씨와 예상 야외 이동을 결합해 사용자가 언제부터 준비하고 무엇을 챙겨야 하
는지를 안내한다.
사용자가 처음 입력한 준비 시간은 확정값이 아니다. 준비 시작 지연, 준비 시간 초과, 출발 지연, 교통 지연을 구분해 다음 계획
을 지속적으로 조정한다.
웰니스는 지도 위의 화려한 레이어가 아니라 행동으로 구현한다. 외출 전에는 선크림·마스크·물·겉옷을 확인하고, 사용자가 동
의한 경우 일정 중에는 선크림 재도포 같은 이벤트 리마인드를 제공하며, 일정 후에는 환경 부담과 촉박함을 정리해 회복 행동을
제안한다.
지도는 외부 지도 API 의 기본 경로 검색과 캘린더 저장에 집중한다. Ensom 의 핵심 경쟁력은 지도 자체가 아니라 준비 시간 학
습, 환경 맥락 해석, 선제적 행동 개입과 사후 웰니스 관리다.
